# Credit Card Fraud Detection App

## 📌 Project Overview
The **Credit Card Fraud Detection App** is a machine learning project designed to identify potentially fraudulent credit card transactions. It uses a trained machine learning model to analyze transaction data and predict whether a transaction is legitimate or fraudulent.

The project demonstrates the practical application of machine learning in financial security and fraud prevention.

## 🎯 Objectives
- Detect potentially fraudulent credit card transactions.
- Apply machine learning techniques to transaction data.
- Provide predictions through an interactive application.
- Demonstrate how machine learning can support financial security.

## 🛠️ Technologies Used
- **Python** – Programming language
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical computing
- **Scikit-learn** – Machine learning
- **Streamlit** – Interactive web application
- **Pickle** – Saving and loading the trained model

## 🚀 Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/FRAUD-DETECTION-APP.git
```

Replace `YOUR-USERNAME` with your GitHub username.

### 2. Navigate to the Project Directory

```bash
cd FRAUD-DETECTION-APP
```

### 3. Create a Virtual Environment (Optional)

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Run the Application

```bash
streamlit run app.py
```

The application will open in your browser.

## 🧠 Machine Learning Workflow
1. Load and explore the transaction dataset.
2. Preprocess the data for model training.
3. Train and evaluate a machine learning model.
4. Save the trained model as `model.pkl`.
5. Load the model in the application.
6. Generate predictions for user-provided transaction details.

## 📊 Project Files
- **`app.py`** – Application interface and prediction logic.
- **`credit_card_fraud_detection.ipynb`** – Data analysis, preprocessing, and model development.
- **`model.pkl`** – Serialized trained machine learning model.
- **`requirements.txt`** – Python dependencies required to run the project.
